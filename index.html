Kontakte vom Gerät übernehmen

Browser dürfen das Adressbuch nicht selbstständig mitlesen. Die Kontakte werden deshalb importiert; ein erneuter Import gleicht die Daten ab (Farben bleiben erhalten).

So exportierst du deine Kontakte
  • iPhone: Kontakte-App → „Listen“ → „Alle Kontakte“ lange drücken → „Exportieren“ → in „Dateien“ sichern, dann hier importieren.
  • Android: Kontakte-App → Einstellungen → „Kontakte exportieren“ (.vcf) → hier importieren.
  • Google/iCloud am PC: contacts.google.com bzw. icloud.com/contacts → Exportieren als vCard.

„Kontakte auswählen“ (nur Chrome auf Android) liefert keine Notizen – dort fehlen dann die NS-Angaben.
